This is a beta test of the first part of the "Corvus Chronicles: Lost City of Ice", a co-op
and single player map by Balr14. The first map is basically complete, except for opening scripts and 
some problem with player positioning at entry (so move off of the entry spot right away). There are 3 
ways to get through this map, once you reach the canyon. The first and most obvious way is the worst. 

The second map is complete. The third is missing some building interior detail and armor shrines. The forth 
map is complete except for the exit, some tweaking of fog density and animation sequence with the sawmill
caretaker.  

You can run this level as single player, but you had best use the easiest settings. It's very tough to get through. 

Contents are:

map 1 - Corvcron
map 2 - ccron1b
map 3 - ccron1c
map 4 - ccron1d
textures - textures/ccron

Unzip the contents to your heretic2/base directory and it will put the stuff where it
belongs.

To play, enter map name corvcron.
