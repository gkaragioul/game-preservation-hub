# Notices, provenance, and content policy

This repository contains original launcher, profile-management, backup, and configuration code written for Oni Modern. The MIT license in [`LICENSE`](LICENSE) applies only to that original code and documentation.

## Not included

This repository and its releases must not contain:

- the commercial game *Oni*, its executable, levels, textures, models, video, music, dialogue, scripts, or other game data;
- a playable or preconfigured game folder;
- Daodan DLL archives, replacement executables, or other community binary packages;
- OniX binaries or converted game-data folders;
- OniSplit binaries, source snapshots, derivatives, or extracted assets.

Users must supply a lawfully obtained copy of *Oni*. The launcher validates a user-selected local installation before making changes and creates timestamped backups of the files it manages.
